04 / Solo creator card

Amiya_desi

Amiya_desi is the public identity I keep for long-running personal work: Godot games, personal websites, homelab notes, Cloudflare workflows, Obsidian writing systems, AI-assisted development notes, tools, posts, and retrospectives. This entry keeps the stable public pieces together: blog posts, GameJam projects, GitHub repositories, GeoScore, a small whiteboard, a guestbook, and public contact links. I use AI for debugging, retrieval, refactoring, docs, and retrospectives, but treat it as an amplifier rather than a substitute for the work itself.

Public Directions

  • Game development: Godot 4.x, GDScript, and C# for 2D prototypes, state machines, event buses, object pools, resources/save systems, and editor tooling.
  • Gameplay expression: platformer movement, time rewind, input buffering/coyote time, level pacing, feel tuning, and meta-leaning narrative puzzle prototypes.
  • Publishing surface: personal site, blog, Bilibili, GitHub, GameJam projects, and public tools and links, slowly turning the portfolio into a growing doorway.
  • Web / homelab: static sites, blog content pipelines, Linux, Docker, Cloudflare Pages / Tunnel, and ops scripts.

Project Notes

  • WakeUpAtTheBorder: Godot 2D narrative platformer about a border-crossing premise, 2nd place in GodotHub 3rd Dev Contest.
  • TimeRuner: C# action platformer built around 5-second rewind and compact level pacing, 034GameJam best time-themed game.
  • EnhanceSaveSystem: Godot save plugin focused on maintainable save engineering: AES-GCM, gzip, atomic writes, and migrations.
  • Mio's Windowanderer / Masquerade of Girls: multi-window puzzle and text-puzzle GameJam work.
