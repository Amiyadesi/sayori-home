whoami.txtAbout me

Indie game developer. I also build the tools.

I make Godot games about time and echoes, and I build websites, tools and servers that actually run.

Over the past year I entered 13 game jams and contests and won 4 awards. Time is the theme I keep returning to: delays, rewinds, echoes, and solving puzzles with your past self.

Outside games I build websites and tools. GeoScore is an open-source SEO / GEO audit service, and Search Gateway is a self-hosted search gateway. I deploy and maintain all of sayori.org and the 31 services behind it myself.

I like to get a working version first, then improve it through play and use. AI speeds up implementation; debugging, trade-offs and game feel are my calls.

time-rewind-linker.lnkTimeRewindLinker

时序链接

2D time-puzzle platformer · 2026-03 · Godot 4.6 · C#

Record a route, rewind, and a beam links your past self to your present self. Doors open only when that beam sweeps across a sensor. Best Time-Themed Game at the 034 Challenge Game Jam #2.

My role
Solo developer

What I built

  • A ring buffer records and rewinds 5 seconds at 30 fps by default, with optional position, velocity and animation fields
  • A TimeController owns time scale and audio pitch together, and lets selected nodes stay immune or frozen
  • Tunable jumps — rise height, rise time and fall curve — with coyote time and input buffering

enhanced-save-system.lnkEnhanced Save System

Save system plugin for Godot 4 · Godot 4 · GDScript / C#

A modular save framework with a global save plus slots, where save modules register and run by priority.

My role
Author

What I built

  • Atomic writes (.tmp, then rename) with optional .bak backups, so an interrupted write never corrupts a save
  • Optional AES-GCM / AES-CBC encryption and gzip / deflate compression, with registered migrations between versions
  • A runtime save manager and an editor bottom panel
