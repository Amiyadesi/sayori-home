Software y servicios

Software y proyectos que desarrollo o mantengo. GeoScore, mi principal SaaS, es gratuito por ahora, sin suscripciones de pago ni cobros en el sitio. Los demás programas y juegos se muestran en su estado real.

SERVICES Servicios públicos Servicios disponibles, código para alojamiento propio, planes y límites de uso. GEO GeoScore Auditorías SEO y GEO de páginas públicas basadas en datos: perfil del sitio, Evidence Map, mejoras prioritarias e informe en Markdown. TOOLS Herramientas Pixela imágenes o córtalas en teselas en el navegador, sin subir el original. Puedes descargar el resultado. BOARD Amiya Whiteboard Una pizarra ligera de navegador para bocetos, diagramas y esquemas de páginas. READ Artículos públicos y RSS Notas sobre sitios web, alojamiento propio, Cloudflare, Godot, desarrollo con IA y retrospectivas, disponibles en la web y por RSS. CODE Search Gateway Proyecto de código abierto que reúne fuentes de búsqueda, conserva instantáneas de las pruebas y ofrece API compatibles e integración MCP. La API de GeoScore sigue la especificación pública, limita las peticiones y valida los destinos públicos. Search Gateway se reserva para mis sitios y su mantenimiento: sin tokens compartidos, llamadas anónimas ni cuotas públicas. NAV Directorio de recursos Herramientas, referencias, comunidades y sitios de código abierto por categorías, con búsqueda interna y externa. NOTE Libro de visitas y avisos de problemas Deja una impresión de lectura o avisa de un problema. Para asuntos de privacidad, abuso o seguridad, también puedes escribirme.

Los demás enlaces seguirán siendo privados hasta que merezca la pena mostrarlos.
