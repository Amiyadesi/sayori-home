Ideas para probar a pequeña escala

No son productos prometidos. Primero usaré invitaciones y revisión manual para evaluar la demanda, los riesgos de abuso y el coste de mantenimiento.

Proyecto por invitación

Intercambio de auditorías web

Auditar con GeoScore blogs personales, páginas de proyectos abiertos y comunidades pequeñas, y añadir una revisión humana con un orden de corrección verificable.

Proyecto por invitación

Ayuda para publicar sitios estáticos

Ayudar a preparar el repositorio, desplegar en Cloudflare Pages o GitHub Pages y dejar documentación para mantener el sitio personal o de código abierto.

Proyecto por invitación

Cuota para verificar fuentes

Una pequeña cuota de Search Gateway para verificar documentación abierta o investigar para una comunidad, sin altas anónimas ni rastreo masivo.

Proyecto por invitación

Reenvío de avisos RSS

Probar avisos poco frecuentes de RSS a correo o webhook para sitios pequeños sin sistema de suscripción, sin campañas comerciales.

Instantáneas temporales de evidencias

Destinar el almacenamiento de objetos disponible a pruebas temporales de GeoScore en vez de reabrir las subidas anónimas.

Límites de uso y criterios de cierre

Definir los límites desde el principio evita que el entusiasmo inicial se convierta en una carga permanente.

  • Mantenimiento según disponibilidad, sin garantía de actividad, tiempo de respuesta ni conservación permanente.
  • Los servicios públicos evitan el registro. Si hacen falta cuentas o datos guardados, se indica.
  • Los abusos, la carga de rastreadores, las cuotas agotadas o los riesgos de seguridad pueden causar límites, pausas o cierres.
  • El almacenamiento privado, las instancias internas de búsqueda y los tokens de gestión no son públicos.
  • Sin alojamiento anónimo de archivos, correo comercial masivo, comunicaciones de emergencia ni servicios de cuentas de alto riesgo.
  • Para avisos sobre abuso, privacidad o seguridad: me@sayori.org.

Por qué no añadir más servicios

Cada servicio añade dominios, supervisión, actualizaciones, gestión de abusos y recuperación de fallos.

Priorizo los servicios que sé mantener, sin subidas públicas, fáciles de limitar y retirar. Retiro los experimentos en pausa de la portada y de los accesos de búsqueda.

Preguntas frecuentes

Esta página describe el software actual, los planes y los límites públicos; no ofrece comprar productos sin publicar.

¿Qué desarrolla Amiya_desi?

Principalmente software web como GeoScore, además de juegos de Godot, herramientas de escritorio y desarrollo y software de código abierto.

¿Hay planes de pago?

No. GeoScore es gratuito y no hay suscripciones de pago ni cobros en el sitio. Antes de vender publicaré precios y condiciones de entrega, reembolso y cancelación.

¿Puedo usar la API de GeoScore?

Sí. Los endpoints estables figuran en OpenAPI y los límites actuales en /api/meta. Audita nombres de host públicos; no es un proxy de URL arbitrarias.

¿Puedo solicitar un token de Search Gateway?

No hay solicitudes públicas. Puedes alojar el código por tu cuenta. Los ensayos pequeños usan invitaciones personales y cuotas explícitas.
