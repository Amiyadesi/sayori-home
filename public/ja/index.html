ソフトウェアとサービス

Amiya_desi が開発・管理するソフトウェアと作品の入口。主な SaaS は GeoScore で、現在は無料。定期課金やサイト内決済はありません。ゲームやソフトは実際の開発状況に沿って紹介します。

SERVICES 公開サービス 公開中のサービス、自分で運用できるソース、今後の予定、利用上の制限。 GEO GeoScore 公開ページを対象に根拠に基づいて SEO・GEO を監査。サイトの概要、Evidence Map、優先修正項目、Markdown レポートを提供します。 TOOLS ツール 画像をブラウザー内でドット絵にしたり、タイルに切り分けたりできます。元画像は送信せず、結果をダウンロードできます。 BOARD Amiya Whiteboard ラフスケッチや簡単な図を描き、ページ構成を説明できる軽量なブラウザー白板。 READ 公開記事と RSS ウェブ制作、セルフホスティング、Cloudflare、Godot、AI を使った開発、制作の振り返り。ウェブでも RSS でも読めます。 CODE Search Gateway 複数の検索元をまとめ、根拠のスナップショットを残すオープンソースのプロジェクト。互換 API と MCP 連携を提供します。 GeoScore API は公開仕様に沿って利用できます。アクセス制限があり、対象が公開ホストか確認します。Search Gateway は管理者自身のサイトと保守用です。トークン共有、匿名呼び出し、公開利用枠はありません。 NAV 資料リンク集 ツール、資料、コミュニティ、オープンソースのサイトを分類。サイト内検索と外部検索が使えます。 NOTE ゲストブックと不具合報告 感想や不具合、改善案を送れます。悪用、プライバシー、セキュリティの問題はメールでも受け付けています。

ほかの入口は、お見せしたくなるまで非公開です。
