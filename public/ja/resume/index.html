whoami.txt自己紹介

インディーゲームを作っています。ツールも作ります。

Godot で時間とこだまを題材にしたゲームを作っています。Web サイトやツールを作り、サーバーも自分で立ち上げています。

この1年でゲームジャムやコンテストに13回参加し、4つの賞を受けました。何度も作りたくなるのは、時間を使った遊びです。少し遅れて起こる動き、巻き戻し、こだま。過去の自分と一緒に謎を解きます。

ゲーム以外では Web サイトやツールを作っています。GeoScore はオープンソースの SEO / GEO 監査サービス、Search Gateway はセルフホスト型の検索ゲートウェイです。sayori.org のサイト群と、それを支える31のサービスは、すべて自分でデプロイし、運用しています。

まずは動くものを作り、遊んだり使ったりしながら直します。実装は AI の力を借りて速く進めますが、デバッグも、何を残すかも、操作感の判断も自分で引き受けます。

  • Godot 4
  • GDScript / C#
  • Cloudflare Workers
  • Python
  • Docker

ゲームの試作、インタラクティブな Web ページ、Web ツールなど、小規模な制作依頼を受け付けています。1件ずつ引き受けて、最後まで仕上げます。

time-rewind-linker.lnkTimeRewindLinker

时序链接

時間を使った2Dパズルアクション · 2026-03 · Godot 4.6 · C#

通った道を記録して巻き戻すと、過去の自分と今の自分が光線でつながります。その光線がセンサーを横切ったときだけ、扉が開きます。034 Challenge Game Jam #2 で時間をテーマにしたゲームの最優秀賞を受賞。

担当
個人開発

実装したこと

  • リングバッファで、標準では直近5秒間を毎秒30フレームで記録・巻き戻し。位置、速度、アニメーションなど、記録する項目は選択可能
  • TimeController で時間の倍率と音声の再生速度を一括管理。特定のノードだけを対象外にしたり、停止させたりすることも可能
  • ジャンプの高さ、頂点までの時間、落下曲線を調整可能にし、コヨーテタイムと先行入力にも対応

delaytrace.lnkDelayTrace

過去の自分に追われる2Dジャンプアクション · 2026-07 · Godot 4.7 · GDScript

実装したこと

  • 同じ部屋に重なる現在・過去・未来の3つの時間軸を使って謎を解く
  • ブラウザでそのままプレイでき、Android 版はタッチ操作に対応
  • 会話は英語と簡体字中国語に対応

enhanced-save-system.lnkEnhanced Save System

Godot 4 用セーブプラグイン · Godot 4 · GDScript / C#

全体で共有するセーブとスロット別のセーブを扱うフレームワーク。セーブ用モジュールは優先度順に登録・実行します。

担当
作者

実装したこと

  • .tmp に書き込んでからリネームするアトミックな書き込みで、中断時もセーブデータを保護。.bak へのバックアップも選択可能
  • AES-GCM / AES-CBC による暗号化と gzip / deflate による圧縮は任意。バージョン間のデータ移行関数を登録可能
  • ゲーム実行中に使えるセーブ管理画面と、エディターの下部パネルを用意
