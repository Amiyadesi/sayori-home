小さく試したいこと

製品化の約束ではありません。まず招待制と個別確認で需要、悪用リスク、運用コストを見て、続けるか決めます。

招待制の計画

サイト診断の助け合い

個人ブログやオープンソースのプロジェクト、小規模コミュニティのサイトを GeoScore で調べ、人の目で確認して検証可能な修正順を添えます。

招待制の計画

静的サイト公開の手伝い

個人・オープンソースのリポジトリを整え、Cloudflare Pages または GitHub Pages に公開し、自分で保守できる手順書を残します。

招待制の計画

調査用の検索枠

オープンソース文書の確認やコミュニティ資料の調査向けに、少量の Search Gateway 利用枠を提供する案です。匿名登録や一括収集は対象外です。

招待制の計画

RSS 通知の中継

購読機能のない小さなサイト向けに、RSS からメールや Webhook への低頻度の通知を試します。広告の一斉配信は扱いません。

非公開の基盤

根拠の短期スナップショット

空いているオブジェクトストレージは、匿名アップロードの再開よりも GeoScore の根拠の短期保存に使います。

非公開の基盤

暗号化バックアップ

残りの容量にはサイト設定、記事の原稿、重要データを暗号化して保存し、復元訓練を記録します。

利用範囲と停止条件

小さな個人サービスを無理なく続けるために、最初からできることの範囲を明確にしています。

  • できる範囲で運用します。稼働率、応答時間、永久保存は保証しません。
  • 公開サービスは原則として登録不要です。アカウントやデータ保存が必要な場合は明示します。
  • 悪用、クローラーの負荷、利用枠切れ、セキュリティ上の問題があれば制限・休止・終了することがあります。
  • 非公開ストレージ、内部検索インスタンス、管理トークンは公開しません。
  • 匿名ファイルホスティング、広告メールの一斉配信、緊急通信、高リスクのアカウントサービスは提供しません。
  • 悪用、プライバシー、セキュリティのご連絡は me@sayori.org へ。

サービスを増やし続けない理由

入口が増えるたび、ドメイン管理、監視、依存関係の更新、迷惑行為への対応、障害復旧も増えます。

経験を生かせて、公開アップロードがなく、利用制限や終了がしやすいものを優先します。休止した実験はトップや検索の入口から外します。

よくある質問

現在のソフトウェア、取り組み、公開範囲を紹介するページです。未発売製品の購入を約束するものではありません。

Amiya_desi は何を開発していますか？

現在は GeoScore のようなウェブソフトが中心です。Godot ゲーム、デスクトップ・開発ツール、オープンソースソフトも作っています。

有料プランはありますか？

ありません。現在 GeoScore は無料で、サイトに有料購読や決済機能はありません。有料化やソフト販売の前に価格、提供方法、返金・解約条件を公開します。

GeoScore API を呼び出せますか？

はい。安定版の公開エンドポイントは OpenAPI に、現在の制限は /api/meta にあります。対象は公開ホスト名のみで、任意 URL のプロキシではありません。

Search Gateway のトークンは申請できますか？

公開申請はありません。ソースから自分で運用できます。小規模な試行は個別招待制で、利用枠を明示します。
