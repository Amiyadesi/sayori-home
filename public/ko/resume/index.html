인디 게임을 만듭니다. 도구도 직접 만듭니다.

Godot으로 시간과 메아리를 소재로 게임을 만듭니다. 웹사이트와 도구를 개발하고 서버도 직접 띄워 운영합니다.

지난 1년 동안 게임잼과 대회에 13회 참가해 상을 4개 받았습니다. 자주 돌아오는 소재는 시간입니다. 뒤늦게 일어나는 일, 되감기, 메아리를 이용해 과거의 나와 함께 퍼즐을 풉니다.

게임 밖에서는 웹사이트와 도구를 만듭니다. GeoScore는 오픈 소스 SEO / GEO 감사 서비스이고, Search Gateway는 셀프 호스팅 검색 게이트웨이입니다. sayori.org의 사이트 전체와 이를 뒷받침하는 서비스 31개를 직접 배포하고 관리합니다.

먼저 돌아가는 버전을 만들고, 직접 플레이하고 써 보며 고칩니다. AI로 구현 속도를 높이되, 디버깅과 설계상의 선택, 조작감에 대한 판단은 제가 맡습니다.

  • Godot 4
  • GDScript / C#
  • Cloudflare Workers
  • Python
  • Docker

게임 프로토타입, 인터랙티브 웹페이지, 웹 도구처럼 작은 규모의 의뢰를 받습니다. 한 번에 한 프로젝트만 맡아 끝까지 완성합니다.
