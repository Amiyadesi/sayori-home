GeoScore 공개 API와 내부 Search Gateway는 이용 범위가 다릅니다 GeoScore API는 공개 문서에 따라 호출하며 요청 제한과 공개 대상 검증을 적용합니다. Search Gateway 인스턴스는 운영자의 사이트와 유지 관리에만 쓰며 토큰 공유, 익명 호출, 공개 할당량을 제공하지 않습니다.

작게 시험해 볼 아이디어

출시를 약속한 제품은 아닙니다. 먼저 초대와 수동 검토로 수요, 악용 위험, 관리 비용을 살핀 뒤 지속 여부를 정합니다.

초대제 계획

사이트 점검 품앗이

개인 블로그, 오픈 소스 프로젝트, 소규모 커뮤니티 사이트를 GeoScore로 점검한 뒤 직접 검토하고 검증 가능한 수정 순서를 제안합니다.

초대제 계획

정적 사이트 출시 지원

개인·오픈 소스 프로젝트의 저장소를 정리해 Cloudflare Pages나 GitHub Pages에 배포하고 직접 관리할 문서를 남깁니다.

초대제 계획

자료 검증용 검색 할당량

오픈 소스 문서 확인과 커뮤니티 자료 조사를 위한 소량의 Search Gateway 할당량입니다. 익명 가입과 대량 수집은 제외합니다.

초대제 계획

RSS 알림 중계

구독 도구가 없는 작은 사이트를 위해 RSS를 이메일이나 웹훅으로 가끔 전송하는 실험입니다. 마케팅 대량 발송은 하지 않습니다.

비공개 인프라

남는 객체 스토리지는 익명 업로드 재개보다 GeoScore 점검 근거의 단기 보관에 우선 사용합니다.

비공개 인프라

암호화 백업

남은 공간에 사이트 설정, 글 원본, 중요 데이터를 암호화해 백업하고 복구 훈련을 기록합니다.

이용 범위와 중단 기준

작은 개인 서비스를 오래 유지하려면 처음의 의욕이 감당하기 어려운 부담이 되기 전에 한계를 밝혀야 합니다.

  • 가능한 범위에서 운영하며 가동 시간, 응답 시간, 영구 보관은 보장하지 않습니다.
  • 공개 서비스는 기본적으로 가입이 필요 없습니다. 계정이나 데이터 저장이 필요할 때는 따로 안내합니다.
  • 악용, 크롤러 부하, 할당량 소진, 보안 위험이 있으면 제한하거나 일시 중지 또는 종료할 수 있습니다.
  • 비공개 저장소, 내부 검색 인스턴스, 관리 토큰은 공개하지 않습니다.
  • 익명 파일 호스팅, 마케팅 대량 메일, 긴급 통신, 고위험 계정 서비스는 제공하지 않습니다.
  • 악용, 개인정보, 보안 문제는 me@sayori.org로 알려 주세요.

서비스를 계속 늘리지 않는 이유

서비스마다 도메인, 모니터링, 의존성 업데이트, 스팸 대응, 장애 복구가 따라옵니다.

기존 경험을 살리고 공개 업로드가 없으며 사용량 제한과 종료가 쉬운 서비스를 우선합니다. 중지된 실험은 홈과 검색 진입점에서 내립니다.

자주 묻는 질문

현재 소프트웨어와 사업 방향, 공개 범위를 설명하는 페이지이며 미출시 제품 구매를 약속하는 곳이 아닙니다.

Amiya_desi는 무엇을 개발하나요?

현재 GeoScore 같은 웹 소프트웨어를 주로 만들며 Godot 게임, 데스크톱·개발 도구, 오픈 소스 소프트웨어도 개발합니다.

현재 유료 요금제가 있나요?

없습니다. GeoScore는 현재 무료이고 사이트 내 유료 구독이나 결제가 없습니다. 판매나 유료화 전 가격, 제공 방식, 환불 및 해지 규정을 공개합니다.

GeoScore API를 호출할 수 있나요?

네. 안정된 공개 엔드포인트는 OpenAPI, 현재 제한은 /api/meta에서 확인하세요. 공개 호스트 이름만 점검하며 임의 URL 프록시가 아닙니다.

Search Gateway 토큰을 신청할 수 있나요?

공개 신청은 받지 않습니다. 소스를 직접 호스팅할 수 있습니다. 소규모 실험은 개별 초대로 진행하며 한도를 명시합니다.
