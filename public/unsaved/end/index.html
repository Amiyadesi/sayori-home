作者仍在这里最后一次试玩

带着两件纪念物，走到最后的窗口。

这次没有人催你。

「起点」把旗插稳了。「工具箱」确认路能走。「旁观者」本来想写一段更漂亮的结束语。

现在，它们把操作权交给你。

最后一幕的规则，你已经学过了。不是要再考一次，只是想让这一段路真正结束在你的手里。

这次没有箱子、预算或隐藏条件。

后记 / 第一面旗 + 工具箱

明天打开的，是工程。

窗口里没出现庆功画面。桌上多了一面旗，一个工具箱，还有一张很短的待办：把下一关做出来。

「起点」又开始讲它那个很帅的 Boss。「工具箱」已经准备好拿材料。「旁观者」伸手拦住了它们。

它这次没有说「你们做不好」。它说：先把第一步给我看看。

于是一个方块又动了起来。和最开始很像，也和最开始不太一样。

这次，作者知道它为什么会动。也知道有个人，曾经陪它走到最后。

后记 / 第一面旗 + 后来补上的话

这一页，有人读到了。

发布说明终于多了一行：可以玩了。

「旁观者」检查了三遍措辞，还是想补一句「其实还有很多不足」。「起点」趁它不注意，把句号换成了感叹号。

最后保留下来的版本，两种标点都有一点。

它不保证作品会被很多人喜欢。也不因为这个保证不存在，就撤回刚才那声开心。

屏幕这边的人并不认识屏幕那边的人。但有一段操作、一点犹豫、一个小小的结尾，已经从一个人那里到了另一个人这里。

后记 / 工具箱 + 后来补上的话

空白也留了位置。

桌面没有被整理成一张漂亮的成绩单。工具箱旁边留了一块空地方，可以放没想清楚的事情，也可以只是放一杯水。

「工具箱」问：明天不用开工吗？「旁观者」说：可以开，也可以先睡一觉。

「起点」担心旗子会不会因此被收走。没有。已经走完的路，不会因为今天停下来就消失。

网页仍然可以打开。那三个版本还会吵架，新的想法也未必总是更成熟。

不过这一次，没有谁需要先证明自己的用处，才能在这一页留个位置。
