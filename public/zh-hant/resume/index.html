whoami.txt關於我

獨立遊戲開發者，順手造工具。

用 Godot 做關於時間與回聲的遊戲，也把網站、工具和服務器做到能跑。

過去一年，我參加了 13 場 Game Jam 與比賽，拿過 4 個獎項。最常做的題材是時間：延遲、回溯、回聲，和過去的自己一起解謎。

遊戲之外，我寫網站和工具。GeoScore 是開源的 SEO / GEO 審計服務，Search Gateway 是自託管的搜索網關。sayori.org 這一整套站點和背後的 31 個服務，都由我自己部署和維護。

我習慣先做出能運行的版本，再靠試玩和使用來改。AI 是加速器：實現可以借它提速，調試、取捨和手感由我自己判斷。

  • Godot 4
  • GDScript / C#
  • Cloudflare Workers
  • Python
  • Docker

現在接小型委託：遊戲原型、互動網頁、Web 工具。一次只接一個項目，保證做完。
